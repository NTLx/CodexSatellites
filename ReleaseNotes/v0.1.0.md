# CodexSatellites v0.1.0

First public release of CodexSatellites.

## Highlights

- Ambient Codex quota satellites around the MacBook hardware notch
- Left satellite for the 5-hour quota window
- Right satellite for the weekly quota window
- Hover-to-reveal remaining percentages
- Compact Launch at Login / Quit settings bar
- Read-only reuse of the existing local Codex login
- Native macOS implementation with no third-party runtime dependencies

## Requirements

- macOS 15+
- MacBook with a hardware notch
- Existing local Codex CLI authentication

## Privacy

CodexSatellites does not implement its own login or OAuth flow. It reads the existing local Codex authentication state and does not refresh tokens or write Codex auth files.

## Known limitations

- Codex usage currently depends on an undocumented ChatGPT usage endpoint.
- Full-screen Space behavior may vary in v0.1.
- No automatic updater yet.

## Integrity

The release includes `SHA256SUMS` for verifying the downloaded DMG.

## Project status

CodexSatellites is an independent community utility and is not affiliated with or endorsed by OpenAI.
