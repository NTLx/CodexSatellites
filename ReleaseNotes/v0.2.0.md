# CodexSatellites v0.2.0

Adds native macOS notifications and tightens the orb interaction.

## Highlights

- Native macOS notifications driven by the configured quota check interval:
  - 5-hour quota reset to 100%
  - weekly quota reset to 100%
  - 5-hour quota crossing below 10%
  - weekly quota crossing below 10%
  - a new available reset credit
  - an available reset credit used
- Simultaneous events produce separate notifications.
- Notification detection is transition-based: the first fetch after launch is a silent baseline.
- Orbs retract immediately when the cursor leaves them.
- Orb collapse no longer clips the circle; the panel frame and content animations share one duration.

## Notification notes

- Notification text is English-only.
- There is no in-app notification toggle; use macOS System Settings → Notifications.
- Delivery requires a signed build and the app to be running.
- The previous snapshot is kept in memory only and is never persisted.

## Requirements

- macOS 15+
- MacBook with a hardware notch
- Existing local Codex CLI authentication

## Privacy

CodexSatellites does not implement its own login or OAuth flow. It reads the existing local Codex authentication state and does not refresh tokens or write Codex auth files.

## Known limitations

- Codex usage currently depends on an undocumented ChatGPT usage endpoint.
- Full-screen Space behavior may vary.
- No automatic updater yet.
- The unsigned preview DMG cannot deliver notifications.

## Integrity

The release includes `SHA256SUMS` for verifying the downloaded DMG.

## Project status

CodexSatellites is an independent community utility and is not affiliated with or endorsed by OpenAI.
