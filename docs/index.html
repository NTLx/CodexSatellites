Before you install

macOS 15 or later and an existing local Codex sign-in. Satellites need a usable built-in MacBook notch; the widget also works on Macs without one, with Launch at Login and Frequency available through macOS Edit Widget.

  1. Download the v0.4.0 DMG from GitHub Releases.
  2. Drag CodexSatellites into Applications.
  3. Launch it. Because v0.4.0 is not notarized, macOS may require you to explicitly approve the app on first open.
  4. Add the widget from the macOS widget gallery if you want it.
Current release · v0.4.0

The app and widget extension are ad-hoc signed; the DMG is not Developer ID signed or Apple-notarized. Verify the download against the published SHA256SUMS file. If macOS blocks the first launch, use Finder’s Open action or review the app in System Settings → Privacy & Security.
