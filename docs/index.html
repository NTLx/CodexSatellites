The satellites

Two satellites, one notch

CodexSatellites leaves the camera housing alone. Two non-activating panels are anchored beside it, so they never steal keyboard focus and never activate the app when you hover.

Left satellite

5-hour quota

The remaining percentage of the short Codex window, shown next to the notch so it is readable without moving your eyes off your work.

Right satellite

Weekly quota

The remaining percentage of the weekly Codex window. Windows are classified by the duration the server reports, not by their order in the response.

Click either satellite

A compact settings bar

Icon-only controls for Launch at Login, quota check interval (1m, 5m, 15m), the read-only count of available reset credits, and Quit. It dismisses itself after three seconds of inactivity, and clicking either satellite closes it immediately.

The widget

The same quotas on your desktop

A WidgetKit widget shows both windows in Small or Medium — on the desktop, in Notification Center, or on any Mac. The notch satellites need a built-in notched display; the widget does not.

Two gauges, two sizes

Small shows both percentages side by side in equal-width, centre-aligned columns. Medium adds when each window resets. Both layouts are illustrations, not live data.

Click the widget

Reload the cached snapshot

Clicking the widget's content area asks macOS for a fresh widget timeline, which re-reads the last quota snapshot the app cached. The click never fetches from OpenAI, never reads your Codex login, never starts the app, and never writes data.

The system margin around the content — roughly the outer 24pt of a Small widget — is not part of that click area; tapping there uses the platform's default widget tap and opens CodexSatellites.

Data flow

How the widget stays current

The app is the only writer: after every quota check it publishes a small snapshot, and the widget is a read-only presentation layer that renders it. The widget has no scheduled refresh, no background task, and no timer; it never reads your Codex login and never calls the usage endpoint. WidgetKit decides when a timeline is requested, and a click is the one interaction that guarantees a reload.

Notifications

Alerts that follow your quota

Native macOS alerts when the 5-hour or weekly window resets to 100%, when either window falls below 10%, and when the available reset count changes. Detection is transition-based, so the first check after launch is a silent baseline. Notification text is English-only, and there is no in-app toggle — macOS System Settings owns that.

Setup

Add the widget

  1. Right-click the desktop and choose Edit Widgets…
  2. Find CodexSatellites in the gallery
  3. Pick Small or Medium and place it

macOS does not let an app place its own widget, and CodexSatellites never tries to.

Freshness

Stale data never pretends

Quota percentages may show the last good reading with reduced opacity, and the available reset count shows — whenever the snapshot is not fresh. A failed refresh keeps the last good data instead of inventing a number.

Privacy

It reads your Codex login. It never manages it.

CodexSatellites only observes the Codex authentication you already have on this Mac, and uses it the same way the Codex CLI does.

What it does

  • Reads the existing local Codex authentication state
  • Uses that existing token to request current usage
  • Runs entirely on-device with native macOS frameworks

What it never does

  • No OAuth, device-code, or browser login
  • No refresh-token exchange, and no writing your Codex auth files
  • No credential storage, telemetry, analytics, or cloud sync
  • No third-party runtime dependencies

Honest about unknowns. Codex usage currently comes from an undocumented endpoint, so the app parses every response defensively. When a value is missing, malformed, or stale, the app shows — instead of guessing, and quota windows are never discarded because of an unrelated parsing failure.

Deliberately not included

CodexSatellites stays small on purpose. It has no menu bar item, no ordinary settings window, no quota history, no cost or token dashboard, no reset countdown, no reset-credit spending, and no other providers. Available reset credits are shown read-only.

Download and install

Download the DMG from GitHub Releases, drag CodexSatellites into Applications, and launch it. On first launch it looks for your existing Codex login and starts polling.
